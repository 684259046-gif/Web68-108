ตำแหน่งที่สนใจ: Frontend Developer (นักพัฒนาส่วนหน้า)

ปัจจุบันเป็นนักศึกษามหาวิทยาลัยราชภัฎนครปฐมสาขาวิชาวิศวกรรมซอฟแวรต์ ตัวผมมีความมุ่งมั่นในการพัฒนาเว็บไซต์ที่ใช้งานง่าย สวยงาม และรองรับการแสดงผลทุกอุปกรณ์ มีความสนใจในเทคโนโลยีเว็บสมัยใหม่และพร้อมเรียนรู้สิ่งใหม่เสมอ

จุดเด่น: เป็นคนที่ถ้าทำอะไรแล้วต้องทำให้ถึงที่สุดชอบลองอะไรใหม่ๆ อะไรที่ไม่ค่อยเข้าใจจะพยายามทำความเข้าใจมันอีกครั้งจนกว่าจะเข้าใจ ตอนนี้ผมได้เรียนรู้เรื่อง HTML, CSS Grid/Flexbox และการเขียนโค้ดที่เป็นระเบียบ
