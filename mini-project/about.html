ประวัติและการศึกษา

ปัจจุบันเป็นนักศึกษาชั้นปีที่ 2 สาขาวิชาวิศวกรรมซอฟแวรต์ มหาวิทยาลัยราชภัฎนครปฐม มีความสนใจด้าน Web Development ตั้งแต่ปีการศึกษาที่ 1 และได้ร่วมทำกิจกรรม/โครงการต่างๆ ในคณะอย่างต่อเนื่อง

เป้าหมายในการทำงาน

เป้าหมายระยะสั้นคือการได้ฝึกงานและทำงานในตำแหน่ง Frontend Developer ในบริษัทเทคโนโลยีเพื่อพัฒนาทักษะการเขียนโค้ดมาตรฐานสูง ส่วนเป้าหมายระยะยาวคือการก้าวสู่ตำแหน่ง Full-Stack Developer

ทักษะด้านเทคนิค

  • HTML5 / Semantic HTML
  • CSS3 (Flexbox, Grid, Responsive)
  • JavaScript (Basic Core & DOM)
  • Git & GitHub
  • Figma (UI Design) ปล.ยังไม่ค่อยคล่องเท่าไหร่แต่จะศึกษาเพิ่มเติมครับ

ทักษะการทำงาน

  • การแก้ไขปัญหา (Problem Solving)
  • การทำงานเป็นทีม (Teamwork)
  • การสื่อสาร (Communication)
